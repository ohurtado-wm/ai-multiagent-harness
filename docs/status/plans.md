# Status: plans

Status, order and hierarchy of the plans in `docs/plans/`, taken from the header of each plan: `status:` (`draft`, `approved`, `in-progress`, `in-validation` or `closed`), `parent:`, `previous:` and `next:`. Format in the [`feature-plan`](../../.claude/skills/feature-plan/SKILL.md) skill. Project summary in [`PROJECT_STATUS.md`](../PROJECT_STATUS.md).

- **Card of a plan** (status, parents, previous, next and children) without reading anything else: `node scripts/plan-status.mjs --plan <file or part of the name>`.
- **Short summary** («Now» as text, the one the session start hook shows): `node scripts/plan-status.mjs --summary`.
- To change something, edit the plan header and run `node scripts/plan-status.mjs`; `scripts/verify.sh docs` fails if this page is stale or a header is inconsistent.
