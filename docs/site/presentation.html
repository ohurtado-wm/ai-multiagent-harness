06 · Enforcement

Hooks: rules that don't depend on memory

Small Node scripts that run before a tool call. Exit code 2 blocks it and tells the agent what to do instead.

Before Bash · everyone

git-guard

  • Commit or push to main / dev
  • PR not against dev
  • rm -rf outside build folders
  • Reading .env
Subagents only

team-guard

  • Any git history change
  • Editing harness config
  • Local DB reset
  • Slow tests without the owner's yes
Before edits

generated-guard

  • Hand-editing generated files
  • Says which source to edit and which command to run
Task created / done

task-gate

  • Plan tasks need a Verification: command
Session start

session-context

  • Injects branch, open PR, touched plans and active plans, written as facts
FAIL CLOSEDSafety hooks run with onFailure: "block": if one crashes or times out, the action is blocked, not allowed. Permission deny rules back them up for pushes to main/dev.

★ CORE10 · The issue loop

Why cut at 250k tokens or 5 PRs?

Measured on four real sessions. The context window is not the limit; the cost of re-reading it on every turn is.

13 · Adoption

Adopt it in ten steps

The apps are placeholders: replace them with your project and keep the harness.

1

Copy the repo. Create dev, make it the default branch, protect main and dev.

2

GitHub Issues. Run scripts/setup-github-labels.sh, enable sub-issues, read the guide.

3

Project context in AGENTS.md; declare the reference app, if any.

4

Areas and commands: plug your stack into scripts/verify.sh and CI.

5

Folder rules: each AGENTS.md (+ CLAUDE.md) with its Code Review Rules.

6

Generated files: list them in generated-guard.mjs.

7

Slow tests: name them e2e-*, integration-*, regression-*.

8

Onboarding: add your toolchain to check.sh.

9

Codex (optional): CLI + Claude Code plugin; without it, coders implement directly.

10

Check it: npm run test:harness and scripts/verify.sh docs.

14 · Honest caveats

What it does not do

It does not make agents infallible: it makes their mistakes visible and keeps irreversible steps in human hands.

Teams are experimental

Falls back to sequential subagents.

Hooks are local

Codex and terminals rely on review, CI and branch protection.

Codex on GitHub

Needs its GitHub integration; the in-team reviewer still runs.

Cost grows with teams

Use a single session or the issue loop for small changes.

Version-dependent

Fail-closed hooks and the 1 h cache need a recent Claude Code.
